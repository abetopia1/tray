# Megaspeed board

Vertical explainer (1080x1920, 30 fps) drawn as one cork board in Remotion.

## Files

| Path | Purpose |
|------|---------|
| `SCRIPT.md` | Narration, source for each line, items left out, source list |
| `script.txt` | Narration text, one paragraph per beat |
| `src/layout.ts` | Every card, tag, stamp and polaroid, with the spoken word it lands on |
| `src/camera.ts` | Camera path along the string, wide shot, final push-in |
| `src/data/words.json` | Word timings. `source` says whether they are estimated or measured from audio |
| `scripts/` | Texture, map, timing and still-frame tools |

## Build

```bash
npm install
node scripts/make-timing.mjs         # estimated timings, until the voice exists
node scripts/stills.mjs 0.5 10 45 95 # check frames at 10 s, 45 s, 95 s
npm run render                       # silent video to out/
```
